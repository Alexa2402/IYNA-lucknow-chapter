## 2026-11-02 - Accessible Controls for Minimalist Dark-Themed Forms
**Learning:** Minimalist landing page forms often rely solely on placeholder text for visual cleanliness, rendering them inaccessible to screen reader users and making input values ambiguous once typed. Furthermore, custom multi-choice role buttons that toggle CSS `.on` classes without `role="group"` and `aria-pressed` leave screen reader users unaware of option groups and active selection states.
**Action:** Pair form inputs with `.sr-only` visually-hidden `<label>` elements and standard autocomplete attributes to preserve visual design while providing complete screen reader support. Group custom role selectors with `role="group"` and announce interactive state changes via dynamic `aria-pressed` attributes.

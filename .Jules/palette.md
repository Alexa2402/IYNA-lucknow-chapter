## 2026-11-03 - Accessible Name and Dynamic Toggle States in Static Forms
**Learning:** In minimalist static websites, forms often omit visible `<label>` elements in favor of input placeholders. While visually clean, placeholders disappear on user input and are frequently skipped or misannounced by screen readers. Furthermore, interactive multi-option role pickers that swap form context dynamically leave screen reader users disoriented unless paired with `role="group"`, `aria-label`, and dynamic `aria-pressed` / `aria-label` updates.
**Action:** Always provide explicit `aria-label` and `aria-required` attributes on placeholder-only inputs, mark custom single-select buttons with `aria-pressed`, and wire dynamic label updates to assistive-technology-facing attributes when switching contexts.
